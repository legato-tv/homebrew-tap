# Legato for Homebrew

[Legato](https://legato.tv) is an IPTV player for Mac (Apple silicon and Intel, macOS 13 and newer). It plays the Xtream Codes account or M3U playlist you already have from your provider. Legato provides no content.

## Install

```sh
brew install --cask legato-tv/tap/legato
```

## Update

```sh
brew upgrade --cask legato
```

Legato is in beta. Other platforms, and how to report a bug: <https://legato.tv/testers>.
